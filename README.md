# Portfolio

Personal portfolio site: low-latency systems, RTL, quant, applied ML and data engineering projects, with the benchmarks behind each claim.

**Live site:** https://sujeeth2003.github.io/Portfolio/

Static site (HTML, CSS, JavaScript), no build step. Project cards are driven by `data.js`; open `index.html` in a browser, or serve the folder with GitHub Pages.

## Structure
- `index.html`: page and layout
- `data.js`: the project list (title, tags, links, thumbnail)
- `rem-dialogues.js`: the mascot's dialogue lines
- `assets/`: hero images, thumbnails and the 3D mascot model

Code for each project lives in its own repository, linked from the cards and from [my profile](https://github.com/sujeeth2003).
